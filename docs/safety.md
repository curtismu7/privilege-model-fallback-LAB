# Safety

What this lab does and does not do, in one page. The tests named here fail if it stops being true.

- **Nothing leaves the machine.** Mock providers, a mock key and a lab clock; the netguard refuses every outbound route and records the attempt (`server/test/netguard.test.js`; the doctor runs every scenario under it and asserts zero attempts). Hosts named anywhere in the lab are `.example` or `.invalid` (`server/test/static.test.js`).
- **Loopback only.** The server binds `127.0.0.1` unless `PMF_BIND` is set on purpose; the Host header must be a loopback name or on `LAB_ALLOWED_HOSTS` (421 otherwise); a write must be same-origin (403 otherwise). Docker publishes `127.0.0.1:7836` only and the image runs as the non-root `node` user with a read-only file system and no capabilities (`scripts/compose.test.mjs`).
- **No credential anywhere.** The key has no credential field: any field the lab does not list (an `apiKey`, a `secret`, a `token`) is refused as unknown. The values shown as credentials in a trace are labelled lab mocks. Nothing secret is logged: a stdout line is `<time> <lab> decision step= actor= result= run=` and never holds a prompt.
- **Hostile input is bounded.** A prompt is a string of at most 20000 characters; a chain has at most 5 models, a model id is 1 to 64 safe characters, a budget a whole number 0 to 1,000,000; bodies over 256 KB are refused; workspace ids are 1 to 32 lowercase letters, digits and dashes and at most 20 exist. Error messages never echo what the caller sent. User text is rendered as text by React and passed through `visible()`, so control and bidi characters show as escapes.
- **The web page is the only thing served besides `/api`.** The page is served from `web/dist` with a content-security policy (`default-src 'self'`); a missing `/assets` file is a 404 and never the page. The tests run without a web build.
- **Nothing is claimed beyond the release notes.** The banner on every page, in presenter mode too, says what is simulated; the Limits page lists what the release notes say and what is the lab's own model (UNVERIFIED). The lab makes no claim about a gateway's own rate-limit refusals.
- **Real mode is not built.** The header toggle shows Real disabled with the reason, and `POST /api/mode {"source":"real"}` answers 409 with the same words. Real, when it exists, is owner-run and read-only.
